### 3.1. Cấu trúc cơ bản

Đây là cách sử dụng cơ bản, hãy sử dụng Code Block để minh họa:

```javascript
// Ví dụ mã nguồn minh họa
function helloWorld() {
  console.log("Xin chào Rury Docs!");
}
```

> **Lưu ý:** Nếu có điểm quan trọng dễ mắc sai lầm, hãy sử dụng blockquote để gây chú ý.
